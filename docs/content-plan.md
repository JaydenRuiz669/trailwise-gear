## Production gates

1. Select a query with a distinct reader decision; inspect current results and avoid duplicating an existing guide.
2. Verify model-specific facts against current primary sources. Save source URLs and the review date.
3. Write an original decision framework, use-case tradeoffs, and explicit limitations. Avoid invented testing, prices, expertise, and first-person experience.
4. Review safety-sensitive claims and remove procedural advice that cannot be responsibly supported.
5. Run the build and link/metadata checks. Review desktop and narrow-screen layouts for template changes.
6. Publish through the existing Worker integration, then verify live pages, sitemap, and a missing-page response.
7. Review Search Console queries and impressions after 28 days of real data. Improve useful pages before increasing publication volume.
