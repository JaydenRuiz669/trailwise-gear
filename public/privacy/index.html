Privacy notice

A plain-language description of this site’s current data practices.

Scope and current features

This notice describes the Trailwise Gear static website prepared on October 26, 2026. The site uses Cloudflare Web Analytics to measure page views and visits. Cloudflare states that Web Analytics does not track individual visitors using cookies or local storage. The site does not include newsletter forms, account systems, payment collection, or embedded videos. We do not measure affiliate clicks with our own site event system. When you click a disclosed affiliate link, Impact and the merchant can process referral information and may use cookies or similar technology under their own policies to attribute qualifying purchases.

Hosting and technical data

The site is served by Cloudflare. Requests necessarily expose technical information such as IP addresses and browser request headers to the hosting provider. Cloudflare may process security, operational, and diagnostic data under its own policies. We have not verified the account’s logging or retention settings, so we do not promise that hosting logs are absent or retained for a particular period.

External links and contact

External websites apply their own privacy practices. Our public contact method uses GitHub; information posted in an issue is public and GitHub processes account and usage data under its own policies. Do not post private or sensitive information. We have no private contact form on this website.

Changes and questions

If we add analytics, forms, advertising, or affiliate tracking, we will review and update this notice to describe the actual implementation. Use the contact page for privacy questions without sharing sensitive details publicly.
