Contact & corrections

Send a question or report a factual error.

Public contact method

Use the public GitHub issue tracker linked below for editorial questions, broken links, and corrections. A GitHub account is required. This is a public channel: do not include an address, phone number, payment information, account credentials, or other private details.

What to include

Include the article URL, the claim or link in question, and a reliable source when possible. For a gear question, include the model and the use case without personal information. We review reports when operating the publication; no response time is guaranteed.

Partnership inquiries

Brands may use the same public channel for non-confidential partnership inquiries. We do not accept payment for undisclosed recommendations or fabricated reviews. Do not send confidential contracts or tax information through an issue.
